# BC LOGO V2 命令与语法参考

- 命令、过程名、变量名均大小写不敏感；文档里用大写只是为了易读。

> 旧版帮助里常见的 `MAKE X 10`、`PRINT X`、`FD X` 已经不能运行。
> 现在分别要写 `MAKE "X 10`、`PRINT :X`、`FD :X`。

---

## 1. 三种“词”

Logo 区分过程名、变量和字面量。BC LOGO 沿用原版 Logo 的写法：

| 写法 | 含义 | 示例 |
|---|---|---|
| `FD`、`SQUARE`、`REPEAT` | 过程/命令调用 | `FD 100` |
| `:X` | 变量 `X` 的值 | `PRINT :X` |
| `"HELLO` | 词字面量 `HELLO` 本身 | `PRINT "HELLO` |
| `123`、`1.5`、`.5`、`1e3` | 数字 | `FD 1.5` |

关键点：

- **裸词是过程调用**。单独写 `X` 表示调用名为 `X` 的过程，不是读取变量。
- **变量必须带冒号**：`:X`。冒号不是运算符，是变量标记的一部分。
- **字面量必须带双引号**：`"X`。`"X` 和 `:X` 看起来只差一个符号，含义完全不同。
- 变量名、过程名由字母、数字、`_`、`#` 组成，不能以数字开头；名字内部的连字符、点号不是名字的一部分（需要的话用带引号的词）。

---

## 2. 词法与源码格式

### 2.1 数字

支持：

```logo
FD 100
FD 1.5
FD .5
FD 5.
FD 1e3
FD 1E-2
```

数字是十进制浮点数；不支持十六进制数字字面量。负号是单独的一元运算符：

```logo
FD -50
PRINT -5 + 2
```

### 2.2 词与引号词

```logo
PRINT "HELLO
SETPC "RED
SETPC "#FF6600
PRINT "A-B
```

带引号的词会一直读到空白、`[`、`]`、`(`、`)`、`,` 或 `;` 为止。因此：

- `"RED` 是词 `RED`；
- `"#FF6600` 是词 `#FF6600`；
- `"HELLO WORLD` 会被拆成两个词（词里不能直接包含空格）；
- 目前不支持 `|带 空格 的词|` 写法，也不支持反斜杠转义。

### 2.3 变量

```logo
MAKE "X 10
PRINT :X
```

- 变量名大小写不敏感；
- `:X` 只能读取已经存在的变量，否则运行期报 `variable 'X' has no value`；
- `MAKE` 的第一个参数也可以是一个变量，用来动态决定变量名：

```logo
MAKE "NAME "Y
MAKE :NAME 7
PRINT :Y
```

输出 `7`。

### 2.4 注释

分号 `;` 到行尾是注释：

```logo
FD 100 ; 前进 100 步
```

### 2.5 行、块和括号

- 一条指令一行；换行也是语句分隔符。
- `[ ... ]` 是命令块，可以包含多条指令，块内用空白/换行分隔。
- 表达式可以在括号 `( ... )` 内跨行；文件模式下这是合法的：

```logo
PRINT (2 +
       3) * 4
```

- 听者按单行输入设计，不建议在听者里输入跨行的方括号块；请把多行代码写进 `.lgo` 文件再“加载文件”。

## 3. 表达式

### 3.1 运算符与优先级

从低到高：

| 优先级 | 运算符 | 说明 |
|---:|---|---|
| 10 | `=` | 相等比较，返回 `1` / `0` |
| 20 | `<`、`>`、`<=`、`>=` | 数值比较，返回 `1` / `0` |
| 30 | 竖线 / `OR` | 逻辑或 |
| 40 | `&`、`AND` | 逻辑与 |
| 50 | `+`、`-` | 加减 |
| 60 | `*`、`/`、`%` | 乘、除、取余 |
| 70 | 一元 `+`、`-` | 正负号 |

> 表中的“竖线”就是键盘上的 `|` 符号；为避免和 Markdown 表格分隔符冲突，正文表格里用文字表示。

括号可以改变优先级：

```logo
PRINT 2 + 3 * 4        ; 14
PRINT (2 + 3) * 4      ; 20
PRINT 10 / 4           ; 2.5
PRINT 10 % 4           ; 2
```

说明：

- `AND`/`OR` 和 `&`/`|` 是**逻辑**运算，不是位运算。
- 算术只接受数字；词参与 `+ - * / %` 会报运行期错误，`+` 也不会拼接词。
- 当前实现会先求值两侧，**不做短路**；不要依赖 `0 AND (1 / 0)` 之类“右侧不会执行”的行为。
- `/` 除以零、`%` 对零取余都会产生运行期错误。
- 比较只接受数字；`=` 可以比较两个词。
- 没有 `NOT`、`<>`、字符串拼接等运算。

### 3.2 数值比较与词比较

```logo
PRINT 3 = 3              ; 1
PRINT 3 < 4              ; 1
PRINT "RED = "red        ; 1（词比较大小写不敏感）
PRINT 1 AND 0            ; 0
PRINT 1 OR 0             ; 1
```

- 数字相等用很小的容差（约 `1e-11`）；
- 词相等不区分大小写；
- 数字和词比较返回 `0`，不会报错；
- `<`、`>`、`<=`、`>=` 遇到词会报运行期错误。

### 3.3 真值

BC LOGO 没有独立的布尔类型：

- `0` 为假；
- 非 `0` 为真；
- `IF`、`IFELSE`、`WHILE` 的条件必须是数字，词会报错；
- 比较和逻辑运算返回数字 `1` / `0`；
- 没有 `TRUE` / `FALSE` 常量，直接写 `1` / `0`。

## 4. 变量与作用域

### 4.1 `MAKE`

```logo
MAKE "X 10
PRINT :X
```

- 变量名参数必须是词（通常是 `"X`，也可以是保存名字的变量 `:NAME`）；
- 值可以是数字或词；
- `MAKE` 会优先修改**当前调用栈中最近的同名变量**；
- 如果找不到同名变量，就创建一个全局变量。

### 4.2 `LOCALMAKE`

```logo
TO TEST
  LOCALMAKE "Y 7
  PRINT :Y
END
TEST
```

`LOCALMAKE` 强制在当前过程帧新建局部变量，即使外层/全局已经有同名变量。

### 4.3 形参与遮蔽

过程形参是当前过程的局部变量：

```logo
MAKE "X 10

TO SHOW :X
  PRINT :X        ; 5
  MAKE "X 20      ; 修改的是 SHOW 的形参
  PRINT :X        ; 20
END

SHOW 5
PRINT :X          ; 10，全局 X 没有被修改
```

输出：

```text
5
20
10
```

这正是原版 Logo 的局部变量/参数遮蔽语义。若旧实现输出 `5 / 5 / 20` 之类的值，那是帧错位 bug，不是本程序现在的行为。

### 4.4 动态作用域

变量查找自当前过程向调用者方向进行。一个过程可以直接读取调用者帧中的变量；`MAKE` 也会修改最近的同名绑定。需要“只在本过程生效”时用 `LOCALMAKE`。

## 5. 过程、参数与返回值

### 5.1 定义过程

```logo
TO SQUARE :N
  REPEAT 4 [FD :N RT 90]
END
```

- `TO` 行写过程名和形参；
- 形参必须带冒号，例如 `:N`；写 `TO SQUARE N` 会报 `E2013`；
- 过程体从下一行开始，遇到 `END` 结束；
- 可以没有参数：

```logo
TO HELLO
  PRINT "HELLO
END
HELLO
```

- 定义过程中的提示行（GUI）：`SQUARE defined.`；重定义时为 `SQUARE redefined.`。

### 5.2 调用与参数

在**语句位置**调用过程时，每个参数按完整表达式解析：

```logo
TO SHOWSUM :A :B
  PRINT :A + :B
END
SHOWSUM 10 + 5 20
```

在**表达式里**调用用户过程时，参数按一元优先级解析；二元运算符会作用在调用结果上：

```logo
PRINT DOUBLE 2 + 1        ; 等价于 (DOUBLE 2) + 1 → 5
PRINT DOUBLE (2 + 1)      ; DOUBLE(3) → 6
```

内置命令（`FD`、`PRINT`、`MAKE`、`REPEAT`……）的参数按完整表达式解析；内置 operation（`SIN`、`COS`、`RANDOM`）在表达式里和用户过程一样按一元优先级解析。需要传一个复合表达式时，加括号最稳妥。

### 5.3 递归与定义顺序

```logo
TO FACT :N
  IF :N < 2 [OUTPUT 1]
  OUTPUT :N * FACT (:N - 1)
END
PRINT FACT 5
```

输出 `120`。

- 过程可以在自己的过程体里调用自己；
- 递归深度上限为 1000，超过会报运行期错误；
- 解析器要求**定义先于调用**；在定义之前调用会报 `E2001`；
- 可以重定义同名过程；之后的调用使用新定义。

### 5.4 `OUTPUT` 与 `OP`

`OUTPUT` 立即结束当前过程，并把一个值交给调用者；`OP` 是它的别名。

```logo
TO DOUBLE :N
  OUTPUT :N * 2
END
PRINT DOUBLE 5
```

输出 `10`。

- 只能在过程体内使用；顶层 `OUTPUT` 是解析错误 `E2012`；
- 一个过程正常执行到 `END` 而没有执行 `OUTPUT` 时，它没有返回值；
- 把没有返回值的过程放在表达式里，会报 `procedure 'F' didn't output`；
- `OUTPUT` 也可以返回词：

```logo
TO GREET
  OUTPUT "HELLO
END
PRINT GREET
```

- `PRINT OUTPUT 5` 是非法写法：`OUTPUT` 已经结束过程，不能作为 `PRINT` 的表达式参数（解析错误 `E2011`）；
- 在语句位置调用一个会返回值的过程时，本程序会打印它的返回值，作为 REPL 便利。

### 5.5 `STOP`

`STOP` 立即结束当前过程，不返回值：

```logo
TO CHECK :N
  IF :N > 0 [STOP]
  PRINT "OK
END
```

- 在过程中：结束当前过程；
- 在顶层：结束当前输入/执行；
- `STOP` 与 `OUTPUT` 都会穿过 `REPEAT`、`IF`、`WHILE` 的块，直到当前过程边界。

### 5.6 命令过程与 operation

用户过程没有单独的“命令/函数”声明；它是否有返回值由是否执行到 `OUTPUT` 决定。

- 语句位置调用：当命令用，返回值会被打印（本程序行为）；
- 表达式位置调用：必须有返回值，否则运行期错误。

## 6. 控制结构

### 6.1 `REPEAT`

```logo
REPEAT 4 [FD 100 RT 90]
```

- 第一个参数是重复次数，向下取整；
- 负数按 `0` 处理；
- 块可以嵌套；
- 循环上限为 1,000,000 次，超过会报运行期错误。

### 6.2 `IF`

```logo
IF :N > 0 [FD 100]
IF 0 [FD 999]        ; 不执行
```

- 条件必须是数字；
- 条件非 `0` 时执行方括号块；
- 没有 `ELSE` 分支；需要二选一时用 `IFELSE`。

### 6.3 `IFELSE`

```logo
IFELSE :N > 0 [FD 100] [BK 100]
```

条件为真执行第一个块，否则执行第二个块。

### 6.4 `WHILE`

```logo
MAKE "I 0
WHILE :I < 4 [FD 25 RT 90 MAKE "I :I + 1]
```

- 每轮重新求值条件；
- 条件为假时结束；
- 循环上限 1,000,000 次；
- `STOP`/`OUTPUT` 会从循环中直接退出当前过程。

## 7. 海龟绘图

### 7.1 坐标系与朝向

- 画布中心是 `(0, 0)`；
- X 轴向右，Y 轴**向下**（屏幕坐标）；
- 初始朝向向上，等价于 heading `-90°`；
- `RT` 增加 heading（顺时针），`LT` 减少 heading（逆时针）；
- 从原点 `FD 100`，终点是 `(0, -100)`；
- `SETX 50` 向右，`SETY -50` 向上。

### 7.2 画笔

- 初始画笔：黑色、线宽 1、落笔；
- `PU` / `PENUP` 抬笔，移动不画线；
- `PD` / `PENDOWN` 落笔，移动画线；
- `SETW n` / `SETWIDTH n` 设置线宽，默认 1；
- `SETPC "RED` 设置画笔颜色；
- `SETBG "YELLOW` 设置背景并清空画布，不移动海龟；
- `SETPCDEC r g b` 用十进制 RGB 设置画笔颜色，分量会夹到 0–255。

颜色参数必须是一个词，也可以来自变量：

```logo
SETPC "RED
SETPC "#FF6600
SETBG "#101820
SETPCDEC 255 128 0

MAKE "COLOR "BLUE
SETPC :COLOR
```

直接写 `SETPC RED` 或 `SETPC #FF6600` 会把 `RED` / `#FF6600` 当作过程名/表达式，通常会得到未知命令错误。原因见第 1 节：裸词是过程调用，不是颜色字面量。

### 7.3 移动命令

| 命令 | 参数 | 作用 |
|---|---|---|
| `FD` / `FORWARD` | 距离 | 沿当前朝向前进；负值后退 |
| `BK` / `BACK` / `BACKWARD` | 距离 | 沿当前朝向后退；负值前进 |
| `LT` / `LEFT` | 角度 | 逆时针转；负值顺时针 |
| `RT` / `RIGHT` | 角度 | 顺时针转；负值逆时针 |
| `SETX` | x | 水平移动到绝对 x；落笔时画线 |
| `SETY` | y | 垂直移动到绝对 y；落笔时画线 |
| `SETXY` | x y | 移动到绝对坐标；落笔时画线 |

`SETX` / `SETY` / `SETXY` 不改变朝向。

### 7.4 清屏、清除与回家

| 命令 | 作用 | 海龟位置/朝向 | 画笔状态 | 背景 |
|---|---|---|---|---|
| `CS` | 清屏并复位 | 回中心，朝上 | 不变 | 变白 |
| `CLEAN` | 清除图形 | 不变 | 不变 | 变白 |
| `SETBG` | 设置背景并清除 | 不变 | 不变 | 变为指定颜色 |
| `HOME` | 回原点；当前实现会画一条到原点的线 | 回中心，朝上 | 不变 | 不变 |

注意：`CS` 不会把画笔颜色、线宽或抬笔/落笔状态恢复为默认值；它只复位位置、朝向和画布。

> `HOME` 的当前实现会无条件画线，即使画笔处于抬起状态。这与标准 Logo“抬笔移动不画线”的行为有差异，属于已知实现细节；写程序时不要依赖“抬笔 HOME 不画线”。

### 7.5 海龟显示

```logo
ST      ; 显示海龟，别名 SHOWTURTLE
HT      ; 隐藏海龟，别名 HIDETURTLE
```

只影响海龟图标，不影响画笔。

## 8. 输入输出与等待

### 8.1 `PRINT`

```logo
PRINT 42
PRINT "HELLO
PRINT :X
PRINT 2 + 3 * 4
```

- 接受一个表达式，输出一行；
- 数字按普通数字格式输出，词原样输出（保留大小写）；
- 输出到 GUI 听者或无头 CLI 的 stdout；
- `PRINT` 是命令，不能出现在表达式位置作为值。

### 8.2 `WAIT`

```logo
WAIT 1000
```

参数单位是毫秒。**当前实现是 no-op**：语法和参数校验保留，但不会真正阻塞。不要依赖 `WAIT` 做动画节拍。

## 9. 数学与逻辑

### 9.1 `RANDOM`

```logo
PRINT RANDOM 6
```

- 返回 `1..n` 的随机正整数；
- `n` 向下取整；`n <= 1` 时返回 `1`；
- 没有 `RERANDOM`/种子命令；需要可重复结果时用 `RANDOM 1`（恒为 1）。

### 9.2 `SIN` / `COS`

```logo
PRINT SIN 30      ; 0.5
PRINT COS 60      ; 0.5
```

- 参数是**角度**，不是弧度；
- 支持负数、超过 360° 的角度；
- 返回浮点数。

> 旧版 `help.docx` 把 `SIN`/`COS` 写成弧度制；当前实现已改为角度制。

### 9.3 逻辑运算

```logo
PRINT 1 AND 0
PRINT 1 OR 0
PRINT 3 = 3
```

- `AND` / `&`：两个数值都非 `0` 返回 `1`，否则 `0`；
- `OR` / `|`：至少一个非 `0` 返回 `1`，否则 `0`；
- 两侧都会先求值，没有短路；
- 没有 `NOT`。

## 11. 错误与诊断

### 11.1 诊断格式

词法/语法错误：

```text
<source>:line:column: error[E2001]: unknown command 'FOO'
```

运行期错误：

```text
Error at line:column: variable 'X' has no value
```

CLI 会写 stderr：

```text
runtime error at 1:7: variable 'X' has no value
```

### 11.2 解析错误码

| 代码 | 含义 |
|---|---|
| `E1001` | 非法字符 |
| `E1003` | 数字格式错误 |
| `E1004` | `:` 后缺少变量名 |
| `E2001` | 未知命令/过程 |
| `E2002` | 缺少表达式/参数 |
| `E2003` | 期望词 |
| `E2004` | 未闭合的 `[` 块 |
| `E2005` | `TO` 缺少 `END` |
| `E2006` | 没有 `TO` 的 `END` |
| `E2007` | 保留名（与内建命令冲突） |
| `E2008` | 条件后缺少 `[` 块 |
| `E2009` | 缺少 `)` |
| `E2010` | 意外 token |
| `E2011` | 命令被当作值 |
| `E2012` | `OUTPUT` 出现在过程外 |
| `E2013` | `TO` 形参缺少 `:` |

解析失败时，该段源码不会被执行；先修掉诊断再运行。

### 11.3 常见错误

| 写法 | 问题 | 改成 |
|---|---|---|
| `MAKE X 10` | `X` 被当作过程调用 | `MAKE "X 10` |
| `PRINT X` | 同上 | `PRINT :X` |
| `FD X` | 同上 | `FD :X` |
| `SETPC RED` | `RED` 被当作过程 | `SETPC "RED` |
| `SETPC #FF0000` | `#FF0000` 是裸词 | `SETPC "#FF0000` |
| `TO SQUARE N` | 形参缺少冒号 | `TO SQUARE :N` |
| `OUTPUT 5`（顶层） | 过程外返回值 | 放进 `TO ... END` 内 |
| `PRINT OUTPUT 5` | `OUTPUT` 是命令，不能当值 | 在过程里 `OUTPUT 5`，调用 `PRINT F` |
| `PRINT F 5`（F 无返回值） | operation 没输出 | 给 F 加 `OUTPUT ...` |
| `IF "YES [...]` | 条件不是数字 | 用比较/数字条件 |

## 12. 与 V1.0 版本语法的差异

下面这些写法已经过时：

| 旧帮助 | 当前 |
|---|---|
| `MAKE X 10` | `MAKE "X 10` |
| `PRINT X` | `PRINT :X` |
| `FD X` | `FD :X` |
| `TO SQUARE N` | `TO SQUARE :N` |
| `SIN rad` / `COS rad` | `SIN 角度` / `COS 角度`（角度制） |
| `SETPC #66ccff` | `SETPC "#66ccff` |
| `SETBG YELLOW` | `SETBG "YELLOW` |
| 只有 `BK/BACKWARD` | 也支持 `BACK` |
| `STOP` 在过程外“没有作用” | 顶层 `STOP` 会结束当前执行 |
| `WAIT` 真正等待 | 当前为 no-op |
| `MAKE` 已存在则“定义”，否则“赋值” | 已存在则修改，否则创建全局 |
| 命令表没有 `OUTPUT` | 支持 `OUTPUT` / `OP` 返回值 |

旧帮助中的 `REPEAT 4[FD 90 RT 90]` 这种“数字后直接跟方括号”的写法仍能解析，但建议统一写成 `REPEAT 4 [FD 90 RT 90]`。

## 13. 当前限制

- 只有数字和词两种值；没有列表、数组、字符串拼接，也没有 `TRUE` / `FALSE` 常量。
- 不支持 `|带 空格 的词|`、反斜杠转义、`NOT`、`<>`。
- 听者单行输入；跨行块请使用 `.lgo` 文件。
- `WAIT` 当前不阻塞。
- 保存只写过程定义，不保存变量值、画布和命令历史。
- `HOME` 当前会无条件画线，即使抬笔；标准 Logo 的“抬笔移动不画线”尚未完全对齐。
- 没有变参过程；过程参数个数在定义时固定。
